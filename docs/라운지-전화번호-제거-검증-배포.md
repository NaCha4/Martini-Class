## [3] 변경 내용

부원 확인과 비회원 문의는 이름·학번만 입력한다. 부원 확인은 현재 학기의 이름·학번이 일치하는 유일한 활성 명부 행만 허용한다. 전화번호 없는 출입 신청과 부원 문의도 처리한다. 새 신청에는 명부의 전화번호를 복사하지 않는다. 응답과 운영진 상세에서도 전화번호를 제공하지 않는다.

세션 만료·명부 변경·재할당 검사는 기존 정보의 해시를 사용한다. 기존 신청·확인 링크·재시도는 호환 처리하며 이전 화면이 전송한 전화번호는 저장하지 않는다. 기존 운영 명부·신청 기록을 일괄 변경하지 않는다.
