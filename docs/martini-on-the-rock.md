# 마티니 온더락

2026-09-28. 운영 지원에 `/admin/on-the-rock`을 추가한다. 활동 중인 임원은 자신의 조를 선택하고 미션 수행을 기록한다.

## 사용 방법

1. 학기를 선택하고 조 이름을 등록한다. 인원 수는 선택 입력이며, 이미지의 실명 명단을 운영 DB에 자동으로 넣지 않는다.
2. 본인의 조를 선택한 뒤 빙고 칸, 반복 미션 또는 특별 미션을 눌러 수행 기록을 저장한다.
3. 빙고 기록에서 **조원 전원 참여**를 체크하면 보라색 원형 樂 도장과 5점 추가 점수를 적용한다. 일반 완료는 붉은색 도장이다.
4. 잘못 기록한 날짜·전원 참여·메모는 수정하고, 잘못 등록한 미션은 취소할 수 있다. 취소된 기록은 이력에 남고 합계에서 제외된다.

미션 인정 여부, 장소, 참여 인원과 반복 간격은 운영진이 판단한다. 3명 이상·24시간 간격 등 원본의 안내는 자동 승인·거절 조건으로 만들지 않는다. 증빙 제출, 승인 대기, 담당 조 강제 배정 기능은 없다.

## 점수

- 빙고는 제공 이미지와 같은 순서의 4×4, 기본 점수 합계 400점이다.
- 전원 참여로 표시한 빙고 칸마다 5점을 더한다.
- 가로 4줄·세로 4줄·대각선 2줄 가운데 완성한 줄마다 30점이다. 모든 칸을 전원 참여로 완료하면 780점이다.
- 반복 미션: 밥 먹기·카페 가기·노래방 가기 각 10점, 술집 가기 20점. 운영진이 등록한 건마다 합산한다.
- 특별 미션: 이벤트 클래스 참여 50점, 주류박람회 방문 70점. 각 미션 완료를 한 번 집계한다.
- 전원 참여 추가 점수는 빙고에만 적용한다. 빙고·반복 미션은 별도 기록이며 인정·중복 여부는 운영진이 판단한다.

## 저장과 영향

새 기록은 `martini_v2_semesters/{학기}/onTheRockGroups/{조}/records/{기록}`에 저장한다. 그룹과 기록을 서버에서 읽어 점수를 계산하고, 기록 작성·수정·취소와 조 등록·수정을 기존 `martini_v2_audit`에 남긴다. 동일 저장 요청을 재전송해도 점수가 중복되지 않고, 오래 열린 수정 화면은 다른 변경을 덮어쓰지 않는다.

기존 임원 로그인·활성 상태·임기 확인을 재사용한다. 다른 자료의 권한, Firestore/Storage 규칙, App Check, IAM, 키, 과금, 도메인과 배포 설정은 변경하지 않는다. 운영 데이터의 이전·삭제·일괄 수정 또는 가상 기록 입력을 실행하지 않는다.

변경 파일은 서버 `on-the-rock.js`, `on-the-rock-rules.js`, `service.js`, 화면 `on-the-rock.js`, `on-the-rock.css`, `admin.js`, `main.js`, Pages 경로를 만드는 `scripts/build.mjs`와 관련 테스트·문서·생성 산출물이다.

## 검증·배포

검증 결과: 단위·실제 HTML 렌더링 테스트 22/22, 기존 Firestore 통합 테스트 98/98, 온더락 통합 테스트 9/9로 총 129개가 통과했다. 조·학기 분리, 재전송·동시 등록, 전체 빙고 780점, 전원 체크 변경, 취소 재집계, 503건의 누락 없는 점수 합산, 기존 임원 인증과 감사 로그를 확인했다. `build:pages` 성공, 36개 파일과 새 직접 접근 경로·참조 자산 존재를 확인했고 비밀 정보 검사·구문 검사·`git diff --check`를 통과했다.

로컬 테스트는 `demo-*` 에뮬레이터만 사용했다. 현재 제공된 도구에는 사용자가 지정한 Browser/Chrome extension 연결이 없어 실제 브라우저 시각·상호작용 검증은 실행하지 않았다. HTML 테스트는 실제 렌더링 함수를 호출하며 브라우저 검증을 대체했다고 간주하지 않는다. 이 테스트의 CSS 로딩 훅에는 Node 22.15 이상이 필요하다(이번 실행 Node 24.8, 에뮬레이터 Java 21). 서버 배포 런타임은 기존 Node 22이다.

`AGENTS.md`의 사전 승인에 따라 서버를 먼저 배포하고, 기능 브랜치를 main에 반영하여 기존 GitHub Pages main/root 경로로 공개 화면을 갱신한다. 별도 인프라 설정 변경은 필요하지 않다.
