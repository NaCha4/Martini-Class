# 가입 신청 제거 검증·배포

2026-09-12. 동아리 가입은 운영진의 별도 Google Form으로 처리하며, 직전 작업에서 추가한 부원 라운지의 자체 가입 접수를 종료한다.

## [1] 브랜치와 Git 상태

`codex/remove-lounge-join`에서 작업했다. 시작 커밋은 `a20b8c6`이며 당시 원격 main과 일치했다. 기능 커밋은 `8bb3c08`이다. 배포 중 main에 들어온 `0614792`의 공개 메뉴 라운지 링크 숨김을 통합하고 정적 산출물을 다시 생성했다. 서버 소스는 통합 중 변경되지 않았다.

## [2] 키·비밀 정보·권한 검사

`check:secrets` 통과. `.env.local`, `serviceAccount.json`, `.secrets`가 없고 민감한 이름·확장자는 Git ignore에 포함된다. 추적된 환경 파일은 `.env.example`뿐이다. 비밀 정보 검색 결과는 검사 스크립트와 기존 CLI 인증 코드의 식별자이며 실제 비밀 값은 발견하지 않았다. 기존 공개 Firebase Web 설정, 임원 권한 검사, Firestore/Storage 규칙, App Check 설정을 유지했다.

## [3] 변경 내용

- 라운지 가입 카드·입력 폼·제출 동작을 제거하고 출입 신청과 문의를 두 칸으로 배치했다.
- 서버는 신규 `kind: join` 요청을 거부하며 출입·문의 접수를 유지한다.
- 관리자 가입 대기 요약과 신규 가입 처리 안내를 제거했다. 이전 가입 기록이 있는 경우에만 ‘이전 가입 신청’ 필터가 나타난다.
- 기존 가입 기록과 개인 확인 링크·관리자 처리·취소 호환성을 유지하며 운영 자료를 삭제하지 않는다.
- 개인정보 추가 안내와 운영 문서를 갱신했다. 기존 `/join` 오픈채팅 안내·설정은 유지하며 Google Form URL을 임의로 추가하지 않았다.
