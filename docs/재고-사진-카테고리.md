# 재고 카테고리 관리 · 2026-10-05

품목은 이름으로 등록하며 카테고리별 텍스트 목록으로 표시한다. 품목을 드래그하거나 이동 버튼을 눌러 카테고리를 변경한다.

## 화면

- 사진 표시·업로드·빈 사진 영역을 제거했다.
- 안내 배너, 소개 문장, 장식용 카테고리 색상, 중복 카테고리 추가 버튼을 제거했다.
- 품목 이름, 수량, 수량 기록과 이동 버튼을 표시한다.
- 등록 폼은 이름을 먼저 입력하고, 단위·용량·최소 수량·보관 위치·메모는 접힌 설정에서 편집한다.
- 카테고리 생성·수정·빈 카테고리 삭제, 검색, 변경 이력을 유지한다.

## 데이터와 호환성

변경 파일은 `web/src/inventory.js`, `inventory.css`, `inventory-forms.js`, `admin-forms.js`와 관련 테스트·문서·공개 빌드 파일이다. 서버 API나 보안 규칙 변경은 없다.

새 폼의 저장 요청은 `photo`를 보내지 않는다. 서버의 기존 병합 처리가 저장된 사진 데이터를 보존하며, 화면에는 표시하지 않는다. 배포 시 운영 데이터 삭제·이관은 수행하지 않는다. 기존 수량·개봉 기록·카테고리·수정 버전 검사와 업무 권한을 유지한다.

## 검증과 배포

실제 렌더러와 이벤트 처리 코드를 사용하는 재고 보드·폼 테스트로 텍스트 표시, 검색, 드래그와 선택 이동, 저장 필드 보존을 확인한다. 사진 업로드 UI에만 해당하던 테스트는 제거했고, 이전 클라이언트와 서버의 사진 입력 검증은 유지한다.

지정된 Browser/Chrome 확장 연결이 없어 실제 브라우저 화면과 터치 조작은 이번 세션에서 확인하지 못했다. 비밀정보 검사·문법 검사·빌드 후 main의 GitHub Pages와 Firebase Hosting에 같은 빌드를 배포한다. 서버 함수 재배포와 IAM·키·과금·도메인 변경은 필요하지 않다.
