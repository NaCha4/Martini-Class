# 결정 · 할 일 전용 카테고리

상단에서 카테고리를 만들고 선택하거나 삭제할 수 있다. 행사명이나 주제를 이름 하나로 입력하면 된다. 활동 운영의 행사와 연결하지 않으며, 일정·정원·참가비 입력이나 행사 관리 권한이 필요하지 않다.

기록 추가 시 선택한 카테고리가 기본으로 지정된다. 기록 수정에서 다른 카테고리 또는 공통 업무로 옮길 수 있다. 회의·안건 연결, 담당자, 기한, 진행 상태와 수정 이력은 유지한다. 카테고리 삭제 시 기록은 공통 업무에 남는다.

주소는 /admin/decisions?category=카테고리ID로 구분한다. 새로고침·뒤로 가기에서 선택이 유지된다. 삭제된 카테고리 주소에는 공통 업무로 이동하는 안내를 표시한다. 이전 행사 연결 주소와 카테고리가 없는 기존 기록은 공통 업무로 표시한다.
