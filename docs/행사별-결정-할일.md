# 행사별 결정 · 할 일

결정 · 할 일 화면 위쪽에서 행사를 선택하면 해당 행사의 기록만 표시한다. 행사 추가는 기존 행사 등록 화면을 열고, 저장하면 새 행사의 업무 화면으로 이동한다. 행사 관리 권한이 있는 임원에게 행사 추가 버튼을 표시한다.

행사에 연결되지 않은 기존 기록은 공통 업무에서 확인한다. 기록을 추가할 때 현재 행사를 기본으로 선택하며, 기록 수정의 관리할 행사에서 다른 행사 또는 공통 업무로 옮길 수 있다. 기존 회의·안건 연결, 담당자, 기한, 상태, 수정 이력을 함께 유지한다.

각 행사는 `/admin/decisions?event=행사ID` 주소로 구분된다. 새로고침과 뒤로 가기에서도 선택이 유지된다. 행사 상세의 준비와 마무리 화면에서도 해당 행사 업무로 바로 이동한다. 보관된 행사에 남은 기록은 계속 확인하고 수정할 수 있다.

## 검증

- 단위 테스트 11개 통과.
- 전용 Firestore 에뮬레이터 테스트 5개 통과: 연결·이동·수정 이력, 구형 클라이언트 호환, 최소 행사 정보와 권한, 500건 초과 페이지 처리, 공통/보관 기록 구분.
- 최신 main을 통합한 뒤 기존 통합 테스트 56개 전체 통과. 전용 Firestore 에뮬레이터의 독립된 테스트 프로젝트에서 실행했다.
- 브라우저 테스트 8개: 데스크톱/모바일에서 행사 선택·새로고침·뒤로 가기, 기록 추가·이동·상태 변경, 상단 행사 추가, 결정 권한 전용 계정과 보관된 행사. 브라우저에서는 로컬 API 응답을 대체하고 실제 화면을 검증했으며, 실제 서버 동작은 별도 Firestore 에뮬레이터 테스트에서 검증했다.
- 비밀 검사 및 빌드 통과. 새 선택 컨트롤의 높이는 최소 44px, 모바일 가로 넘침 없음.
