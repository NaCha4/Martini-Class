# 행사별 결정 · 할 일

결정 · 할 일 화면 위쪽에서 행사를 선택하면 해당 행사의 기록만 표시한다. 행사 추가는 기존 행사 등록 화면을 열고, 저장하면 새 행사의 업무 화면으로 이동한다. 행사 관리 권한이 있는 임원에게 행사 추가 버튼을 표시한다.

행사에 연결되지 않은 기존 기록은 공통 업무에서 확인한다. 기록을 추가할 때 현재 행사를 기본으로 선택하며, 기록 수정의 관리할 행사에서 다른 행사 또는 공통 업무로 옮길 수 있다. 기존 회의·안건 연결, 담당자, 기한, 상태, 수정 이력을 함께 유지한다.

각 행사는 `/admin/decisions?event=행사ID` 주소로 구분된다. 새로고침과 뒤로 가기에서도 선택이 유지된다. 행사 상세의 준비와 마무리 화면에서도 해당 행사 업무로 바로 이동한다. 보관된 행사에 남은 기록은 계속 확인하고 수정할 수 있다.
